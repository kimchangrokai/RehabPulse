# M0 조사 메모 — ssgo.scourt.go.kr

## 사이트 정보

- **URL**: `https://ssgo.scourt.go.kr/ssgo/index.on?cortId=www`
- **사이트 유형**: WebSquare 기반 동적 웹 앱 (iframe 아님)
- **탭**: 사건번호로 검색 / 인증서로 검색 (우리는 사건번호만 사용)

## 조회 흐름 (PRD §5 기반)

```
법원 선택 → 년도 선택 → 사건구분 선택 → 일련번호 입력 → 당사자명 입력 → 캡차 입력 → 검색
```

### 주의사항
- 사건구분은 법원에 따라 목록이 바뀌므로 **법원을 먼저** 선택해야 한다
- 캡차 이미지는 **매 검색마다** 바뀐다. 이전 캡차를 재사용하면 안 된다
- 당사자명은 **필수 입력**. 빈 이름으로 제출하면 거짓 결번이 발생할 수 있다
- Google 번역 바가 폼을 가릴 수 있다 — 닫고 진행

### 진행내용 → 진행구분 = 명령
- 진행내용 탭 → 진행구분 드롭다운을 **명령**으로 변경
- 필터된 목록의 법원 행정명령 내용을 행 단위로 저장

핵심 명령:
| 명칭 | 이벤트 |
|---|---|
| 변제계획인가결정 | PLAN_APPROVED ★ |
| 개인회생절차개시결정 | COMMENCED |
| 개인회생절차개시신청 기각결정 | DISMISSED |
| 기각취소결정 | DISMISSAL_VACATED |

## DOM 구조 (추정 — 실제 브라우저 확인 필요)

### WebSquare 환경
- 라벨(`법원 선택`, `당사자명 필수입력`)을 id보다 우선
- select/combo 요소는 WebSquare 커스텀 컴포넌트일 수 있음
- 사건구분 목록은 법원 변경 시 AJAX로 갱신

### 결과 탭 구조
- 성공 시 일반내용 / 진행내용 탭이 나타남
- 일반내용: th(라벨) + td(값) 테이블 구조
- 진행내용: 진행구분 드롭다운 + 명령 테이블
