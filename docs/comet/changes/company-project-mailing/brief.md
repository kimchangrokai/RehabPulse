# Outcome

회사 → 프로젝트로 사건·담당자·메일링을 나눈다. 프로젝트마다 xlsx와 sidecar YAML이 있고, 조회(04:00)와 메일(07:00)이 분리되며, 프로젝트는 독립 프로세스로 병렬 조회한다. 실패는 재시도 후 남은 이상(결번 포함)을 관리자에게 알린다.

# Scope

- 초기 회사/프로젝트: `대신증권/2608계약건`, `삼성증권/2608계약건`
- 경로: `data/{회사}/{프로젝트}.xlsx` + `data/{회사}/{프로젝트}.yaml`
- 담당자(이름+이메일)와 메일링 리스트 분리. 변경·보고서 메일은 프로젝트 메일링 리스트
- CLI `sync`/`report`는 `--company` 또는 `--project` 필수
- 기본 조회 04:00, 기본 메일 07:00. 프로젝트별 Windows 작업이 독립 세션으로 동시에 돌아도 된다
- 일일 점검: 재시도 후 남은 이상(보고서 없음, SMTP 실패, 조회 error, 결번 miss 포함)은 `realtyscope.ai@gmail.com`
- 시드 6건 이전 없음. 초기 메일링: `sonaba79@gmail.com`, `kimchangrok.ai@gmail.com`

# Non-goals

- 다중 사용자 로그인/SaaS
- 캡차 우회, 포털 조회 규칙(하루 2회·3일 결번 카운트) 변경
- 회사 권한/인증 모델
- 회사 단위 메일링 리스트
- 전역 단일 `rehabpulse.xlsx`
- 한 프로세스에서 전 프로젝트 순차 조회

# Acceptance examples

- A1: `data/대신증권/2608계약건.xlsx`와 `data/삼성증권/2608계약건.xlsx`가 생성되고, 각 메일링 리스트에 `sonaba79@gmail.com`, `kimchangrok.ai@gmail.com`이 있다.
- A2: 담당자(이름+이메일, 복수)와 메일링 리스트가 별개다. 변경 메일은 메일링 리스트만 받는다.
- A3: 같은 법원+사건번호를 두 프로젝트에 각각 등록할 수 있다. 한 워크북 안 중복 등록은 거절된다.
- A4: `python -m rehabpulse sync` 또는 `report`에 `--company`/`--project`가 없으면 오류로 종료하고 포털을 치지 않는다.
- A5: sidecar YAML에 `lookup_time: "04:00"`, `mail_time: "07:00"`이 기본으로 들어간다.
- A6: 두 프로젝트 조회 작업이 같은 시각에 서로 다른 프로세스로 동시에 실행될 수 있다.
- A7: 메일 시각에는 엑셀에서 보고서를 만들어 보낸다(포털 재조회 없음). SMTP 실패는 2회 재시도한다. 재시도 후에도 실패·error·결번(miss)이 있으면 관리자 `realtyscope.ai@gmail.com`에게 메일을 보낸다.

# Constraints and invariants

- 포털 원문 값을 정규화로 잃지 않는다.
- SMTP 비밀번호는 환경변수만.
- 한 사건 실패가 같은 프로젝트의 다른 사건 조회를 중단시키지 않는다.
- 프로젝트 세션은 브라우저·캡차 클라이언트를 공유하지 않는다.
- 관리자 알림 주소: `realtyscope.ai@gmail.com`
- 조회는 평일(법원 업무일). 메일·점검도 같은 평일 창을 따른다.

# Decisions

- Q1: 프로젝트마다 xlsx 하나
- Q2: 담당자와 메일링 리스트 분리
- Q3: 변경 메일은 프로젝트 메일링 리스트만
- Q4: 유일 키는 워크북 내부(법원+사건번호). 프로젝트 간 중복 허용
- Q5: `--company` 또는 `--project` 필수
- Q6: TEST 초기 회사/프로젝트/메일링. 시드 6건 이전 없음
- Q7: `data/{회사}/{프로젝트}.xlsx`
- Q8: 회사 메일링 없음
- Q9: 스케줄은 `data/{회사}/{프로젝트}.yaml`
- Q11: 기본 조회 04:00, 기본 메일 07:00. 프로젝트별 독립 세션 병렬
- Q12: 권장 재시도 + 남은 이상은 결번 포함 모두 관리자 메일
- 조회와 메일 시각 분리
- 관리자: `realtyscope.ai@gmail.com`
- 가정: 평일만 조회/메일/점검 (법원 사이트). 주말은 작업을 건너뛰고 관리자 알림을 보내지 않음
